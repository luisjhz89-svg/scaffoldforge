# ScaffoldForge

ScaffoldForge is a CLI generator for product-ready starter projects. It helps teams skip repetitive setup and start building value faster.

## Quick start

```bash
npm install
npm link
scaffoldforge list
```

## Create your first project

```bash
scaffoldforge init my-dashboard --template react-vite --description "Analytics dashboard"
```

Then:

```bash
cd my-dashboard
npm install
npm run dev
```

## Deploy the landing page

This project is ready to be deployed as a static site on Vercel.

### Vercel settings

- Framework Preset: Other
- Build Command: leave blank
- Output Directory: .
